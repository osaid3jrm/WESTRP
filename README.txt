WESTRP Website
================

1. فك ضغط الملف.
2. ارفع مجلد WESTRP كاملاً إلى الاستضافة أو افتح index.html للتجربة.
3. لا يوجد ملف icons.svg مطلوب. جميع الأيقونات مكتوبة SVG داخل صفحات HTML حتى لا تتعطل بسبب تحميل ملف خارجي.
4. ملفات الموقع:
   - index.html
   - news.html
   - rules.html
   - departments.html
   - events.html
   - about.html
   - contact.html
   - assets/style.css
   - assets/main.js

ملاحظة: نصوص الأخبار والقطاعات والفعاليات والقوانين أمثلة مؤقتة، استبدلها بالمعلومات الرسمية المعتمدة.
رابط Discord في contact.html تجريبي ويجب استبداله برابط دعوتك.
